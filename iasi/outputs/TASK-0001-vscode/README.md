# IASI VS Code extension candidate

Run `npm install`, then `npm test`. The compiled extension is emitted to `dist/`. Open this folder in VS Code and press `F5` to launch an Extension Development Host.

`.iasi` files are associated with the IASI language. Commands are available in the Command Palette as `IASI: Open Source`, `IASI: Open Preview`, and `IASI: Open Split View`. Preview updates when the source document changes. Metadata errors appear as editor diagnostics. Preview HTML is sanitized, scripts are disabled, and only HTTP(S)/mailto links are allowed.

The extension candidate is not published to a marketplace.
